## English

### Product name

Panopticon

### Short description

See, organize, and activate your open Windows apps through live desktop thumbnails, flexible layouts, filters, and workspaces.

### Full description

Panopticon turns your open Windows desktop into a visual control room.

See real top-level windows through live previews rendered by Windows Desktop Window Manager. Switch between Grid, Mosaic, Bento, Fibonacci, Columns, Row, and Column layouts. Filter or group windows by application, monitor, title, class, or tag, then activate the window you need without repeatedly cycling through Alt+Tab.

Panopticon can stay available in the system tray, respond to a global shortcut, and optionally work as an appbar/dock. Save workspace-specific settings, customize themes and backgrounds, and create per-application rules for visibility, aspect ratio, color, tags, and preview behavior.

The application is local-first. It does not require an account. The Microsoft Store build relies on Microsoft Store for package updates and does not use Panopticon's GitHub Releases update request.

Live previews can display sensitive information already visible in another open application. Panopticon keeps those previews local, but users should review the dashboard before sharing screenshots or recordings.

### Features

- Live DWM previews of open desktop windows
- Seven layouts: Grid, Mosaic, Bento, Fibonacci, Columns, Row, and Column
- One-click window activation
- Filters and grouping by application, monitor, title, class, and tag
- Per-application visibility, color, aspect-ratio, tag, and refresh rules
- Tray hide/show workflow
- Configurable global activation shortcut
- Optional appbar/dock mode
- Named workspaces and local settings
- Themes, color overrides, backdrop opacity, and local background images
- English and Spanish interface
- Keyboard-accessible navigation and command palette
- Local-first operation without a Panopticon account
